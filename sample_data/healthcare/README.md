# Healthcare sample documents

Real public documents only (blank forms, published samples, training examples). No real patient data: every name and number
in a filled sample is the publisher's invented example.

| Folder | Files | Source |
|---|---|---|
| claims/ | CMS-1500 blank (4 pp); UB-04 blank fillable (Oklahoma), UB-04 samples (Texas AG, Aetna Better Health, Carepatron) | cms.gov, gateway.sib.ok.gov, texasattorneygeneral.gov, aetnabetterhealth.com, carepatron.com |
| forms/ | New-patient intake and medical-history forms (Stony Brook, Wake Forest, Fusion Wellness, Carepatron fillable), immunization card (Washington), vaccine administration record (Maryland, fillable), NPI application CMS-10114 (fillable) | each organisation's public site |
| clinical/ | CBC lab report (testing.com), blood smear (ARUP), pathology reports (Roswell Park, Globe Life example), discharge summary template and examples (UTHSC, Carepatron), filled prescription (Carepatron) | public sites |
| payer/ | Explanation-of-benefits samples: CMS, Maryland Health Dept, Highmark (CMU), BCBS Illinois, Missouri State | public sites |

Some are guides with an annotated sample inside rather than a pure document (EOB guides, the Aetna UB-04 instructions).

Other healthcare files sit in the sample_data root: a member/provider prior-authorisation pair and a Medicaid provider prior-auth form.
